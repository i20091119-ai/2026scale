## 2. 수학 모델: 저울 ↔ 등식 대응

수평 조건: **Σ(무게 × 거리)왼쪽 = Σ(무게 × 거리)오른쪽**

- 거리 1칸의 추 `3` → 등식의 항 `3`
- 거리 2칸의 추 `3` → 등식의 항 `3×2`
- 목표 칸(거리 d)의 빈 자리 → 등식의 `□×d` (d=1이면 그냥 `□`)

사칙연산 표현:

| 연산 | 등식 예 | 저울 상황 |
|---|---|---|
| 덧셈 | `3 + 4 = □` | 왼팔 3, 4 (거리1) / 오른팔 빈칸(거리1) |
| 뺄셈 | `9 = 4 + □` | 빈칸 쪽에 이미 4가 있음 → □ = 9 − 4 |
| 곱셈 | `3×2 = □` | 3이 거리 2칸에 있음 → □ = 6 |
| 나눗셈 | `12 = □×3` | 빈칸이 거리 3칸 → □ = 12 ÷ 3 |

## 3. 난이도 · 출제 · 점수

- 난이도 10단계, 단계별 10문제(시드 고정 난수로 생성·중복 제거) = 총 100문제.
- n번째 문제(1~10)는 n단계 풀에서 랜덤 1개 추출 → "100개 풀 + 랜덤 + 점진 난이도"를 동시 충족.
- 1~3단계: 거리 1칸만(덧·뺄셈). 4~5단계: 곱·나눗셈 도입. 6~10단계: 혼합·항 수 증가·수 확대.
- 모든 정답과 제시 추는 1~18(보유 일러스트 범위) 안에서만 출제.
- 점수: 기본 100점 − 오답시도 × 20 (최저 40) + 남은시간 × 2 + 연속정답 보너스(10 × 콤보, 최대 50).
- 시간 초과: 정답 추가 자동으로 올라가 수평이 되는 모습을 보여준 뒤 다음 문제(0점).

## 4. 추가 제안 (요구 10)

1. **기울기 시연 피드백**: 오답 추를 올리면 실제로 무거운 쪽으로 기울어지는 애니메이션 + "○○쪽이 더 무거워요!" 안내 → 지렛대 원리를 몸으로 이해.
2. **콤보/시간 보너스**: 연속 정답과 빠른 풀이에 보너스 → 재도전 동기.
3. **효과음 전부 WebAudio 합성**: 음원 파일·네트워크 불필요, 음소거 버튼 제공.
4. **어트랙트 모드**: 방치 시 시작화면 복귀, 시작화면에 둥둥 떠다니는 추 애니메이션으로 관람객 유인.

## 5. 전시 환경(키오스크) 대응

- 1920×1080 기준 설계 후 화면 크기에 맞춰 자동 스케일(전자칠판 해상도 무관).
- `touch-action: none`, 텍스트 선택·롱프레스 메뉴·더블탭 확대 차단.
- 외부 네트워크 자원 0개 — 완전 오프라인 동작.
- 일정 시간(90초) 무입력 시 시작화면 자동 복귀.
