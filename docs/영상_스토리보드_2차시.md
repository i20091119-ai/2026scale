- 소재: **기사의 여행 대결** (실제 제작 완료된 앱 기준: 1~4인 동시 대결 · 각자 5×5 보드 · 제한시간 2분 · 새 칸 +10점 · 25칸 완주 +100점 · 막히면 자동 새 판 · 말발굽 힌트가 판이 거듭될수록 사라짐)
- 규격·자막 규칙: 1차시와 동일 (MP4 · 16:9 · FHD · 4:45 목표 · 전 구간 대사 자막)

# 시리즈 설계 (1·2차시 역량 구분)

**시리즈 주제: "교실마다 있는 전자칠판, 교사가 직접 만드는 터치형 수업 앱"**
— 널리 보급된 전자칠판을 활용해 각 교실에 알맞은 웹앱을 교사 스스로 제작하는 역량을 기르고, 수업과 학급경영에 활용한다.

| | 1차시 (수평을 맞춰라!) | 2차시 (기사의 여행 대결) |
|---|---|---|
| 부제 | 처음부터 완성까지 | 두 번째 앱은 하루면 |
| 핵심 질문 | "코딩 없이 앱을 만들 수 있을까?" | "이 역량으로 우리 교실을 어떻게 바꿀까?" |
| 앱 유형 | 개인 도전 · 교과(수학) 게임 | **동시 대결 멀티플레이**(1~4인 분할 화면) · 전략/사고력 게임 |
| 기르는 역량 | ① 과업지시서 쓰기 ② AI 협업 ③ 에셋 제작 ④ 피드백 ⑤ 무료 배포 | ① 재사용으로 빠르게 ② **규칙·숫자를 말로 설계** ③ **수업 노하우를 게임 규칙으로**(스캐폴딩) ④ 아이들과 베타테스트 ⑤ 학급 앱 서랍 |
| 활용 장면 | 수업(개념 도입·정리) | **학급경영**(모둠 대표전·아침 활동·자투리 시간) + 수업 |
| 시청 후 상태 | "나도 만들 수 있겠다" | "우리 반에 맞게 계속 만들어 쓰겠다" |

> 1차시의 5단계는 2차시에서 반복 설명하지 않는다. 2차시는 "이미 아는 사람"이
> 두 번째 앱을 얼마나 빠르게, 그리고 얼마나 교사답게 만드는지를 보여준다.
