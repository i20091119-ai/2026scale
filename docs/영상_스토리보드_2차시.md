# 시리즈 설계 (1·2차시 역량 구분)

**시리즈 주제: "교실마다 있는 전자칠판, 교사가 직접 만드는 터치형 수업 앱"**
— 널리 보급된 전자칠판을 활용해 각 교실에 알맞은 웹앱을 교사 스스로 제작하는 역량을 기르고, 수업과 학급경영에 활용한다.

| | 1차시 (수평을 맞춰라!) | 2차시 (기사의 여행) |
|---|---|---|
| 부제 | 처음부터 완성까지 | 두 번째 앱은 반나절 |
| 핵심 질문 | "코딩 없이 앱을 만들 수 있을까?" | "이 역량으로 우리 교실을 어떻게 바꿀까?" |
| 앱 유형 | 개인 도전 · 교과(수학) 게임 | **팀 대항 멀티플레이** · 전략/사고력 게임 |
| 기르는 역량 | ① 과업지시서 쓰기 ② AI 협업 ③ 에셋 제작 ④ 피드백 ⑤ 무료 배포 | ① 재사용으로 빠르게 만들기 ② 게임 **규칙을 말로 설계** ③ **우리 반 맞춤** 커스터마이징 ④ 아이들과 베타테스트 ⑤ 학급 앱 라이브러리 운영 |
| 활용 장면 | 수업(개념 도입·정리) | **학급경영**(모둠 대항·아침 활동·자투리 시간) + 수업 |
| 시청 후 상태 | "나도 만들 수 있겠다" | "우리 반에 맞게 계속 만들어 쓰겠다" |

> 1차시에서 배운 5단계는 2차시에서 반복 설명하지 않는다. 2차시는 "이미 아는 사람"이
> 두 번째 앱을 얼마나 빠르고 우리 반답게 만드는지를 보여준다.
