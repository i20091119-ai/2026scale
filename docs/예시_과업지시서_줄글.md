# 예시 — 교사가 직접 쓴 과업지시서 (줄글본)

> 영상 STEP 1(C9)에서 화면에 보여줄 실제 지시서 예시.
> 개조식이 아니라, 교사가 AI에게 편하게 부탁하듯 쓴 줄글.
> 이 글을 그대로 생성형 AI(클로드 등)에 붙여넣으면 첫 버전이 나온다.

---

안녕, 나는 경남수학문화관에서 근무하는 교사인데 체험전시관에서 쓸 웹앱을 하나 만들고 싶어. 교실이나 전시관에 있는 터치형 전자칠판에서 손가락으로 조작하는 방식이야.

내가 만들고 싶은 건 저울로 하는 수학 게임이야. 화면에 저울이 하나 있고, 저울 양쪽 팔에 무게추(숫자가 적힌 추)를 올려서 수평을 맞추는 게 목표야. 그런데 그냥 무게만 보는 게 아니라, 저울 팔에 가운데에서부터 거리를 나타내는 칸이 있어서, 같은 무게라도 어느 칸에 놓느냐에 따라 수평이 달라지게 하고 싶어. 지렛대 원리처럼 무게 곱하기 거리로 계산되게 말이야. 그래서 이미 한쪽에 추가 몇 개 올라가 있는 상태에서, 어떤 추를 어디에 놓아야 수평이 될지 아이가 맞히는 거지.

그리고 화면 위쪽에는 등호가 있는 수식을 하나 보여주고 싶어. 거기에 네모 빈칸이 있어서, 이 빈칸에 들어갈 숫자를 맞히는 것과 저울에서 수평을 맞추는 게 사실 같은 문제가 되도록 연동해줘. 수식에 이미 나와 있는 숫자들도 저울에 올라가 있는 추랑 맞아떨어지게 하고. 문제 수준은 처음엔 자연수 사칙연산 정도면 좋겠어.

문제는 백 개 정도 미리 만들어 두고 랜덤으로 나오게 해줘. 아이가 계속 맞힐수록 점점 어려워지게 하고 — 놓아야 하는 추가 늘어난다든지, 사칙연산이 복잡해진다든지 하는 식으로. 한 판은 열 문제로 끝나고, 다 풀면 축하 화면을 보여주면 좋겠어. 문제 하나당 제한시간도 두고, 맞힐 때마다 점수가 올라가게 해줘.

무게추는 손가락으로 끌어다 놓는(드래그) 방식으로 하고 싶어. 무게추 그림은 내가 따로 준비할 테니까, 나중에 그림 파일만 바꿔 끼우면 되도록 만들어줘. 수학문화관 로고도 화면에 넣어줘.

전체적으로 아이들이 좋아하게 최대한 귀엽고 예쁘게 만들어줬으면 좋겠고, 화면 크기가 달라도 잘 보이게 해줘. 세부적인 화면 구성이나 편의 기능은 네가 좋다고 생각하는 대로 제안해서 넣어줘도 좋아. 혹시 이 게임에 어울리는 다른 아이디어가 있으면 그것도 알려주고.

마지막으로, 바로 코드부터 짜지 말고 내가 부탁한 내용을 먼저 네가 정리하고 분석해서 보여준 다음에 시작해줘. 다 만들고 나면 스스로 한번 실행해보면서 문제가 없는지 확인까지 해주면 좋겠어.
