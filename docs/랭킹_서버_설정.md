# 랭킹 서버(구글 시트) 설정 가이드

랭킹을 구글 시트에 저장해서 **모든 전자칠판이 하나의 랭킹을 공유**하게 만드는 설정입니다.
5분 정도 걸리고, 한 번만 하면 됩니다. 직원은 시트에서 행을 지우는 것만으로
부적절한 닉네임을 삭제할 수 있습니다.

대상 시트: https://docs.google.com/spreadsheets/d/1SGrV8sZo4oFY_n2TukpN8z8p4Y8vGpgbhjBJ3BfLi48/edit

## 1단계 — Apps Script 열기

1. 위 시트를 엽니다 (시트 소유 계정으로 로그인).
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
3. 편집기에 기본으로 있는 코드를 모두 지우고, 아래 코드를 **전체 붙여넣기** 합니다.

```javascript
// ═══════════ 수평을 맞춰라! 랭킹 서버 ═══════════
var SHEET_NAME = '랭킹';
var MAX_SCORE = 10000;                       // 이 점수를 넘는 기록은 거부(조작 방지)
var BANNED = ['시발', '씨발', '병신', '새끼', '존나', '좆', '니미', 'fuck', 'shit', '섹스'];

// 랭킹 조회 (상위 50개)
function doGet(e) {
  var rows = getSheet().getDataRange().getValues();
  var list = rows.slice(1)
    .map(function (r) {
      return { n: String(r[1]), s: Number(r[2]), d: new Date(r[0]).getTime() };
    })
    .filter(function (x) { return x.n && !isNaN(x.s); });
  list.sort(function (a, b) { return b.s - a.s || a.d - b.d; });
  return json({ ok: true, list: list.slice(0, 50) });
}

// 기록 등록
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var name = String(data.name || '').trim().slice(0, 8);
    var score = Math.round(Number(data.score));
    if (!name || isNaN(score) || score < 0 || score > MAX_SCORE) {
      return json({ ok: false, error: 'invalid' });
    }
    var lower = name.toLowerCase();
    for (var i = 0; i < BANNED.length; i++) {
      if (lower.indexOf(BANNED[i]) >= 0) { name = '★★★'; break; }
    }
    getSheet().appendRow([new Date(), name, score]);
    return json({ ok: true });
  } catch (err) {
    return json({ ok: false, error: 'parse' });
  }
}

function getSheet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = ss.getSheetByName(SHEET_NAME);
  if (!sh) {
    sh = ss.insertSheet(SHEET_NAME);
    sh.appendRow(['시각', '닉네임', '점수']);
  }
  return sh;
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

4. 💾 저장(프로젝트 이름은 아무거나, 예: "저울게임 랭킹").

## 2단계 — 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 클릭.
2. ⚙️(유형 선택) → **웹 앱** 선택.
3. 설정:
   - 설명: 아무거나 (예: 랭킹 v1)
   - 실행 계정: **나(내 계정)**
   - 액세스 권한: **모든 사용자** ← 중요!
4. **배포** 클릭 → 권한 승인 창이 뜨면 계정 선택 → "고급" → "…(안전하지 않음)로 이동" → 허용.
   (내가 방금 만든 스크립트라서 안전합니다. 구글의 표준 경고입니다.)
5. **웹 앱 URL**(https://script.google.com/macros/s/…/exec)을 복사합니다.

## 3단계 — 게임에 URL 연결

`js/config.js` 파일을 열어 복사한 URL을 붙여넣습니다:

```javascript
window.GameConfig = {
  RANKING_API_URL: 'https://script.google.com/macros/s/여기에_붙여넣기/exec'
};
```

GitHub에서 직접 수정해도 되고, URL을 저(Claude)에게 주시면 반영해 드립니다.

## 운영 안내

- **랭킹 관리**: 시트의 "랭킹" 탭에서 행을 삭제하면 그 기록이 랭킹에서 사라집니다.
- **금칙어**: 위 코드의 `BANNED` 목록을 수정하면 됩니다(게임 쪽에도 같은 1차 필터가 있음).
  금칙어에 걸린 이름은 '★★★'로 바뀌어 저장됩니다.
- **오프라인 대비**: 전자칠판이 인터넷에 연결되지 않으면 자동으로 그 기기에만 저장되고,
  연결이 돌아오면 밀린 기록을 자동으로 서버에 올립니다. 랭킹 화면 상단에
  "🌐 전체 전시장 랭킹" / "📴 서버 연결 안 됨" 상태가 표시됩니다.
- **코드 수정 후**: Apps Script 코드를 고쳤다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**
  를 해야 반영됩니다 (URL은 그대로 유지됨).
