# 문제풀 전체 목록 (100문제)

난이도 10단계(초1~중3) × 각 10문제. 게임에서 n번째 문제는 n단계에서 랜덤으로 1문제가 출제됩니다.
이 목록은 `js/problems.js`가 생성하는 풀과 동일하며(시드 고정), 브라우저에서 `problems.html`을 열어도 볼 수 있습니다.

> 저울 배치 읽는 법: **7@2** = 무게 7 추가 거리 2칸에 올려져 있음, **★@d** = 정답 추를 올릴 목표 칸.
