# 마이크로러닝 영상 스토리보드
## "전자칠판 수업 앱, 교사가 직접 만든다" (가제)

- 공모: 경상남도교육청 교육연수원 「2026. 모두가 나누는 학교생활 이야기」
- 규격: MP4, 16:9, FHD(1920×1080) 이하, 24~30fps, 4.5Mbps 이하, 1분당 15MB 이하 → **5분 영상 기준 총 70MB 이하**
- 분량: 최소 2분 ~ 최대 5분 → **목표 4분 45초** (여유 15초 확보)
- 심사: 최신성 30 / 적절성 30 / 윤리성 30 / 완성도 10 (80점 이상 선정)
- 시청 대상: 경남 교직원 (연수 콘텐츠 — "나도 할 수 있겠다"는 노하우 전달이 목적)

# 2. 초안 자체 점검 (심사 기준 대비)

**문제 1 — 훅이 없다.** 마이크로러닝은 첫 15초에 시청을 계속할 이유를 줘야 하는데, 초안은 타이틀→1분짜리 인터뷰로 시작한다. 연수 영상에서 인터뷰가 먼저 나오면 이탈률이 높다. → **"완성된 앱을 즐기는 장면"을 먼저 보여주고 "이거, 교사가 만들었습니다"라는 반전을 훅으로** 쓴다.

**문제 2 — 핵심 메시지의 비중 부족.** 이 영상의 연수 가치는 "교사가 스스로 만드는 방법"인데 초안은 뒤쪽 150초에 앱 소개까지 섞여 있다. 심사 기준 '적절성(사례 중심, 단순 지식전달 지양)'을 고려하면 **제작 과정을 단계별 실제 사례 화면으로 보여주는 부분이 영상의 중심(2분 이상)**이 되어야 한다.

**문제 3 — 인터뷰 60초는 너무 길다.** 전문가 인터뷰는 신뢰도(적절성 점수)에 기여하지만, 말하는 얼굴 60초는 지루하다. → **35~40초로 압축하고, 발언 내용 위에 게임 화면(B-roll)을 겹쳐** 지루함을 없앤다.

**문제 4 — 윤리성(30점) 대비가 없다.** ① AI 활용 사실 명시(자막·크레딧), ② 음원·폰트 저작권(내장 폰트는 SIL OFL 무료 라이선스, BGM은 공유마당·무료 음원 사용 명시), ③ 초상권(학생 대신 동의받은 교사 체험 장면 사용, 학생 등장 시 보호자 동의). 이 세 가지를 제작 노트에 명시한다.

**문제 5 — 완성도(10점) 요건.** 모바일 무음 시청 대비 **전체 자막 필수**, 화면 축소를 고려한 큰 글자, 캡처 화면은 확대(줌인) 편집.

**문제 6 — 시간 초과 위험.** 5:00 상한에 딱 맞추면 편집 오차로 탈락 사유가 될 수 있다 → 4:45 목표.

# 4. 제작 노트

**시간 합계**: 20+8+42+38+137+25+15 = **285초 = 4분 45초** ✅ (상한 5분 대비 15초 여유)

**촬영 체크리스트**
- [ ] 전자칠판 체험: 풀샷/손 클로즈업/리액션 3컷 이상, 정답 팡파레 순간 필수
- [ ] 연구원 인터뷰: 조용한 공간, 가슴샷, 전체 발언 녹취 후 38초로 편집
- [ ] 화면 녹화: 게임(1080p), AI 대화, 시트, 배포 화면 — 캡처는 확대 편집 전제로 원본 크게
- [ ] 출연자 초상권 동의서 (학생 등장 시 보호자 동의)

**윤리성(30점) 대비**
- AI 활용 사실을 나레이션+크레딧에 명시 (숨기지 않는 것이 강점)
- BGM·효과음: 공유마당/유튜브 오디오 보관함 등 상업적 이용 가능 음원만, 출처 크레딧 표기
- 서체: 영상 자막도 무료 라이선스 서체 사용 (예: Sunflower, 프리텐다드)
- 앱 자체가 순수 창작물(에셋 자작·폰트 OFL)임을 크레딧에 한 줄 표기

**완성도(10점) 대비**
- 전 구간 자막 (무음 시청 대비), 자막 크기: 모바일 축소 고려 최소 60px(1080p 기준)
- 인코딩: 1080p / 30fps / 3.5~4Mbps / 5분 기준 70MB 이하 확인
- 단계 배지·개념 자막은 동일 템플릿으로 통일

**나레이션 분량 감각**: 한국어 나레이션은 초당 4~5자. 각 구간 대본이 "구간 길이 × 4.5자"를 넘지 않게 리허설로 확인.
