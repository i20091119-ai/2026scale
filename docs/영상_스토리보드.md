# 마이크로러닝 영상 스토리보드
## "전자칠판 수업 앱, 교사가 직접 만든다" (가제)

- 공모: 경상남도교육청 교육연수원 「2026. 모두가 나누는 학교생활 이야기」
- 규격: MP4, 16:9, FHD(1920×1080) 이하, 24~30fps, 4.5Mbps 이하, 1분당 15MB 이하 → **5분 영상 기준 총 70MB 이하**
- 분량: 최소 2분 ~ 최대 5분 → **목표 4분 45초** (여유 15초 확보)
- 심사: 최신성 30 / 적절성 30 / 윤리성 30 / 완성도 10 (80점 이상 선정)
- 시청 대상: 경남 교직원 (연수 콘텐츠 — "나도 할 수 있겠다"는 노하우 전달이 목적)
- **배분 원칙: 앱 소개 + 제작법이 전체의 80%** (나머지 20%: 훅·타이틀·전문가 코멘트·아웃트로)

| 5 | 4:40~5:00 (20초) | 아웃트로 | 정리 + 로고 |

# 2. 자체 점검

1. **훅 부재** — 첫 15초에 시청을 계속할 이유가 없음 → "완성작을 즐기는 장면 → 사실 교사가 만들었다" 반전 훅으로 교체.
2. **본론 비중 부족** — 연수 가치의 핵심(소개+제작법)이 150초(50%)뿐 → **전체의 80%로 확대** (확정 반영).
3. **인터뷰 60초는 과함** — 전문가 코멘트는 신뢰 부여용 20초로 압축, 발언 위에 게임 화면(B-roll).
4. **윤리성(30점) 대비** — AI 활용 명시, 무료 음원·OFL 서체, 초상권 동의를 크레딧과 제작 노트에 반영.
5. **완성도(10점)** — 전 구간 자막(무음 시청 대비), 모바일 축소 고려한 큰 글자, 캡처 화면 확대 편집.
6. **시간 여유** — 상한 5:00에 딱 맞추면 위험 → 4:45 목표.

# 5. 제작 노트

**촬영 체크리스트**
- [ ] 전자칠판 체험: 풀샷/손 클로즈업/리액션, 정답 팡파레 순간 필수
- [ ] 연구원 코멘트: 조용한 공간, 가슴샷 — 전체 녹취 후 10초 핵심만 사용
- [ ] 화면 녹화: 게임 플레이(1080p), AI 대화, 시안 PDF, 에셋 전후 비교, GitHub Pages 설정, 구글 시트
- [ ] 출연자 초상권 동의서 (학생 등장 시 보호자 동의)

**윤리성(30점) 대비**
- AI 활용 사실을 나레이션+크레딧에 명시 (숨기지 않는 것이 강점)
- BGM·효과음: 공유마당/유튜브 오디오 보관함 등 상업적 이용 가능 음원만, 출처 표기
- 자막 서체도 무료 라이선스(Sunflower, 프리텐다드 등)
- 앱이 순수 창작물(에셋 자작, 폰트 OFL)임을 크레딧에 한 줄 표기

**완성도(10점) 대비**
- 전 구간 자막(무음 시청 대비), 자막 크기 1080p 기준 60px 이상
- 캡처 화면은 확대(줌인) 편집 — 모바일에서 글자가 읽혀야 함
- 단계 배지·개념 자막 템플릿 통일
- 인코딩: 1080p / 30fps / 3.5~4Mbps / 총 70MB 이하 확인

**나레이션 분량**: 한국어 초당 4~5자. 각 구간 대본이 "길이 × 4.5자"를 넘지 않는지 리허설로 확인.
