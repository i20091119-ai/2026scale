# 윈도우 설치판 가이드 (자동 업데이트)

게임을 Windows에 **설치파일(.exe)** 로 설치해 전체화면 키오스크로 실행하는 방법입니다.
설치된 PC는 **실행할 때마다 자동으로 최신 버전으로 갱신**됩니다.

## 1. 설치하기

1. 저장소의 **Releases** 페이지(`https://github.com/i20091119-ai/2026scale/releases`)에서
   최신 `BalanceScale-Setup-x.x.x.exe` 를 내려받습니다.
2. 실행 → 설치 위치 선택 → 설치. 바탕화면과 시작 메뉴에 **"수평을 맞춰라"** 아이콘이 생깁니다.
3. Windows가 "확인되지 않은 앱" 경고(SmartScreen)를 띄우면 **추가 정보 → 실행** 을 누릅니다.
   (코드 서명 인증서 없이 만든 설치파일이라 뜨는 표준 경고입니다.)

## 2. 실행하면 일어나는 일

```
아이콘 실행
  → 스플래시 화면 "업데이트 확인 중…"
  → GitHub에 신호 하나: 게임 브랜치의 최신 커밋 번호 조회
  → 로컬에 저장된 번호와 비교
       같음        → "최신 버전입니다" → 바로 게임 시작
       다름        → 게임 파일 묶음 다운로드(약 18MB) → 교체 → "업데이트 완료!" → 게임 시작
       인터넷 없음 → "업데이트를 건너뜁니다" → 기존 버전으로 게임 시작
```

- 즉, **저장소에 푸시(Pages 배포)만 하면** 다음 실행 때 모든 설치 PC가 자동으로 새 버전이 됩니다.
- 업데이트는 게임 파일(html/css/js/그림)만 교체합니다. 실행기(껍데기)는 그대로라 재설치가 필요 없습니다.
- 랭킹 기록·음소거 설정 같은 로컬 저장 데이터는 업데이트해도 유지됩니다.

## 3. 종료하기 (관리자용)

키오스크 모드라 창을 닫는 버튼이 없습니다. 두 가지 방법으로 종료합니다.

| 방법 | 동작 |
|---|---|
| **화면 오른쪽 위 모서리를 빠르게 5번 연속 터치** | 종료 (버튼이 없는 빈 곳을 2.5초 안에 5번. 버튼 위 터치는 세지 않음) |
| `Ctrl` + `Alt` + `Q` | 종료 (키보드가 있을 때) |
| `Ctrl` + `Alt` + `U` | 지금 업데이트 확인 후 다시 시작 |

## 4. 부팅 시 자동 실행 (전시장 PC)

설치 후 한 번 실행하면 아래 폴더가 생깁니다:

```
C:\Users\<사용자>\AppData\Roaming\balance-scale-kiosk\
```

여기에 `settings.json` 파일을 만들고 다음 내용을 넣으면 Windows 로그인 시 자동으로 시작합니다:

```json
{ "autoStart": true }
```

(같은 폴더의 `kiosk.log` 에 업데이트 확인·적용 기록이 남습니다. 문제가 생기면 이 파일을 보내주세요.)

## 5. 어느 브랜치를 따라가나? (채널 변경)

실행기는 `desktop/channel.json` 의 브랜치를 따라갑니다. 현재는
`claude/math-museum-balance-scale-3klq4n` 입니다.

나중에 `main` 으로 옮기고 싶으면 **저장소의 `desktop/channel.json` 만 고치면** 됩니다.
실행기는 시작할 때 Pages에 올라간 이 파일을 먼저 읽기 때문에, 설치된 PC를 재설치하지 않아도
다음 실행부터 새 브랜치를 따라갑니다.

## 6. 새 설치파일 만들기

설치파일은 **GitHub Actions(Windows 빌드 서버)** 가 자동으로 만듭니다. 사람이 Windows PC에서
빌드할 필요가 없습니다.

- **정식 배포**: 저장소에 `v1.0.1` 같은 태그를 푸시하면 자동으로 빌드되어 Releases에 올라갑니다.
  ```
  git tag v1.0.1 && git push origin v1.0.1
  ```
  (`desktop/package.json` 의 `version` 도 같은 번호로 맞춰 주세요.)
- **시험 빌드**: GitHub → Actions → "Build Windows installer" → **Run workflow**. Release는 만들지 않고
  아티팩트로만 남깁니다.

게임 내용만 바뀐 경우에는 새 설치파일이 **필요 없습니다** — 자동 업데이트가 처리합니다.
실행기 자체(단축키·업데이트 방식 등 `desktop/` 폴더)를 고쳤을 때만 새 설치파일을 만듭니다.

## 7. 직접 Windows PC에서 빌드하려면 (선택)

Node.js 20 이상이 설치된 Windows PC에서:

```
cd desktop
npm install
npm run dist
```

`desktop/dist/BalanceScale-Setup-x.x.x.exe` 가 생성됩니다.

## 8. 자주 묻는 것

- **인터넷이 아예 없는 전시장이면?** 설치 시점의 게임이 그대로 실행됩니다. 랭킹은 그 PC에만 저장됩니다.
- **학교 프록시 환경이면?** 실행기가 Windows 시스템 프록시 설정을 그대로 따릅니다.
- **업데이트 도중 전원이 꺼지면?** 새 파일은 별도 폴더에 다 받은 뒤 한 번에 바꿔치기하므로, 도중에 끊겨도 기존 게임은 멀쩡합니다.
