기본 그래픽은 전부 코드로 그려져 있지만, 아래 이름으로 이미지를 올리면 **자동으로 교체**됩니다.
일부만 올려도 되고, 파일을 지우면 다시 기본 그래픽으로 돌아갑니다.

## 3. 글상자·버튼류 (CSS로 그림)

수식 칩, 안내 말풍선, 정답 카드, 버튼, 목표 칸(? 상자) 등은 코드(CSS)로 그리기 때문에
이미지가 아니라 **스타일 값**으로 맞추는 게 깔끔합니다. 원하는 느낌을 알려주시면 맞춰 드립니다:

- 색상(배경/테두리/글자), 모서리 둥글기, 그림자 정도, 테두리 두께·점선 여부
- 예: "수식 칩은 크림색 바탕 + 갈색 두꺼운 테두리 + 모서리 많이 둥글게"

꼭 이미지로 만들고 싶은 글상자가 있으면 말씀 주세요. 해당 요소에도 교체 슬롯을 추가해 드립니다
(9-패치 방식으로 어떤 크기에도 대응 가능).

## 4. 참고 좌표 (1920×1080 기준)

- 헤더: y 0~96 / 타이머 바: y 96~114
- 수식 카드: 좌상단 또는 우상단 (36, 126)부터 — 저울과 겹치지 않게 자동 이동
- 저울 회전축: (960, ≈544) / 저울대 길이 1100px / 거리 한 칸 125px
- 안내 문구: y ≈ 710 / 보관함: y ≈ 830~1010, 중앙 정렬
- 무게추 표시 크기: 보관함 130×152, 저울 위 104×122
