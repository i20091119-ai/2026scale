# 에셋 업로드 위치

GitHub은 빈 폴더를 보여주지 않기 때문에 이 안내 파일로 폴더를 만들어 두었습니다.
아래 경로에 파일을 올려 주세요.

| 에셋 | 경로 | 비고 |
|---|---|---|
| 수학문화관 로고 | `assets/logo.png` | 이 폴더에 `logo.png` 이름으로 업로드 |
| 무게추 일러스트 18종 | `assets/weights/weight-01.png` ~ `weight-18.png` | [weights 폴더 안내](weights/README.md) 참고 |
| 축하 영상(선택) | `assets/celebration.mp4` | 없으면 내장 폭죽 연출 사용 |

- 로고는 가로형 PNG(투명 배경 권장)면 어떤 크기든 자동으로 맞춰집니다.
- 파일이 없어도 게임은 내장 그래픽으로 정상 동작합니다.
