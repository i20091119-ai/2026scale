# 무게추 일러스트 업로드 위치

보유하신 무게추 일러스트 18종을 **이 폴더**에 아래 이름으로 업로드해 주세요.

```
assets/weights/weight-01.png   ← 숫자 1 무게추
assets/weights/weight-02.png   ← 숫자 2 무게추
...
assets/weights/weight-18.png   ← 숫자 18 무게추
```

- 파일명은 반드시 두 자리 숫자(`weight-01.png` ~ `weight-18.png`)로 맞춰 주세요.
- 권장 규격: 투명 배경 PNG, 정사각형에 가까운 비율(예: 500×580px 내외).
- 파일이 없는 번호는 게임에 내장된 대체 그래픽(파스텔 추 + 숫자판)이 자동으로 표시되므로,
  일부만 먼저 올려도 정상 동작합니다.
