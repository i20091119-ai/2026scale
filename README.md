# ⚖️ 수평을 맞춰라! — 균형 저울 게임

경상남도교육청 **경남수학문화관(GNMC)** 체험전시관의 터치형 전자칠판용 웹 콘텐츠입니다.
저울의 수평 맞추기(지렛대 원리)와 등식의 빈칸(□) 채우기가 하나로 연동된 수학 체험 게임입니다.

## 실행 방법

빌드가 필요 없는 순수 정적 웹앱입니다. 외부 네트워크 자원을 전혀 쓰지 않으므로 **완전 오프라인**으로 동작합니다.

```bash
# 아무 정적 서버로 열기 (예시)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

전자칠판에서는 브라우저를 전체화면(키오스크 모드)으로 실행하는 것을 권장합니다.
어떤 해상도든 1920×1080 기준 화면이 자동으로 맞춰집니다.

## 게임 규칙

- 화면 위 등식의 **□에 들어갈 수**를 생각하고, 무게추 보관함에서 추를 **드래그**해 저울의 반짝이는 **? 칸**에 올립니다.
- 수평 조건은 지렛대 원리를 따릅니다: **무게 × 거리**의 합이 양쪽에서 같아야 수평!
- 총 10문제 · 제한시간은 1단계 100초에서 단계마다 5초씩 감소(10단계 55초), 시간 초과 시 게임 종료 · 난이도는 **초1(한 자리 덧셈)부터 중3(미지수가 양쪽에 있는 일차방정식)까지** 단계별 상승.
- 문제풀: 난이도 10단계 × 10문제 = 100문제에서 랜덤 출제.
  전체 목록은 [`problems.html`](problems.html)(브라우저) 또는 [`docs/문제풀_전체.md`](docs/문제풀_전체.md)에서 열람.
- 점수 = **문제 단계(1~10) × 남은 시간(초)** 합산, 최대 3,850점.
- **1,500점 이상으로 완주하면 🔥 보너스 문제 2개** 도전 자격 획득: 전용 최고 난도 풀에서 출제되며 11·12단계로 취급(제한시간 50초·45초, 점수 배율 11×·12×).
- 1~4단계에서는 스캐폴딩(추마다 값 풍선, 양팔 합계, 드래그 미리보기)으로 무게×거리 개념을 익힙니다.
- 10문제 종료 시 축하 연출(폭죽·팡파레)과 함께 등급이 표시되고,
  닉네임을 입력해 **명예의 전당(TOP 10)** 에 기록할 수 있습니다(내장 한글 터치 키보드, localStorage 저장).

## 에셋 업로드 위치

| 에셋 | 경로 |
|---|---|
| 무게추 일러스트 18종 | `assets/weights/weight-01.png` ~ `weight-18.png` ✅ 적용됨 |
| 수학문화관 로고 | `assets/logo.png` ✅ 적용됨 |
| 서체 | `assets/fonts/Sunflower-Bold.ttf` ✅ 썬플라워 B 전체 적용 (SIL OFL) |
| 배경·타이틀·저울·보관함 등 커스텀 디자인 | `assets/ui/` — 규격은 [`docs/디자인_가이드.md`](docs/디자인_가이드.md) |
| 축하 영상(선택) | `assets/celebration.mp4` — 있으면 결과 화면 배경에 재생, 없으면 내장 폭죽 연출 |

에셋이 없어도 내장 대체 그래픽으로 완전하게 동작합니다.
