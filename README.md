# ⚖️ 수평을 맞춰라! — 균형 저울 게임

경상남도교육청 **경남수학문화관(GNMC)** 체험전시관의 터치형 전자칠판용 웹 콘텐츠입니다.
저울의 수평 맞추기(지렛대 원리)와 등식의 빈칸(□) 채우기가 하나로 연동된 수학 체험 게임입니다.

## 실행 방법

빌드가 필요 없는 순수 정적 웹앱입니다. 외부 네트워크 자원을 전혀 쓰지 않으므로 **완전 오프라인**으로 동작합니다.

```bash
# 아무 정적 서버로 열기 (예시)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

전자칠판에서는 브라우저를 전체화면(키오스크 모드)으로 실행하는 것을 권장합니다.
어떤 해상도든 1920×1080 기준 화면이 자동으로 맞춰집니다.

## 게임 규칙

- 화면 위 등식의 **□에 들어갈 수**를 생각하고, 무게추 보관함에서 추를 **드래그**해 저울의 반짝이는 **? 칸**에 올립니다.
- 수평 조건은 지렛대 원리를 따릅니다: **무게 × 거리**의 합이 양쪽에서 같아야 수평!
- 총 10문제 · 문제당 30초 · 풀수록 난이도 상승(덧셈 → 뺄셈 → 곱셈 → 나눗셈 → 혼합).
- 문제풀: 난이도 10단계 × 10문제 = 100문제에서 랜덤 출제.
- 점수: 기본 100점 − 오답 시도당 20점(최저 40) + 남은 시간 × 2 + 연속 정답 보너스.
- 10문제 종료 시 축하 연출(폭죽·팡파레)과 함께 등급이 표시됩니다.

## 에셋 업로드 위치

| 에셋 | 경로 |

| 무게추 일러스트 18종 | `assets/weights/weight-01.png` ~ `weight-18.png` ([상세 안내](assets/weights/README.md)) |
| 수학문화관 로고 | `assets/logo.png` |

에셋이 없어도 내장 대체 그래픽으로 완전하게 동작합니다.
